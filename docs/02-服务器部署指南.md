# 货记服务器部署指南

本文档用于把当前 Web 版货记部署到一台已安装 Docker 的云服务器。

## 1. 云服务器控制台

先确认安全组或防火墙已开放：

- `22`：SSH 登录
- `80`：HTTP 访问
- `443`：HTTPS 访问

开发端口如 `5176` 不需要开放到公网。

## 2. 登录服务器

在本机终端执行：

```bash
ssh root@你的服务器公网IP
```

如果云厂商给的是 Ubuntu 普通用户，则使用：

```bash
ssh ubuntu@你的服务器公网IP
```

## 3. 安装基础工具

容器镜像服务器通常已经有 Docker。登录后先检查：

```bash
docker version
docker compose version
```

如果缺少 Git：

```bash
apt update
apt install -y git
```

## 4. 拉取代码

```bash
mkdir -p /opt/huoji
cd /opt/huoji
git clone 你的代码仓库地址 .
```

如果暂时还没有远程 Git 仓库，也可以先用压缩包或 `scp` 上传项目目录。

## 5. 配置生产环境变量

```bash
cp .env.production.example .env.production
nano .env.production
```

先用 IP 测试时：

```env
APP_HOST=:80
APP_URL=http://你的服务器公网IP
DEEPSEEK_API_KEY=你的 DeepSeek Key
SMS_PROVIDER=mock
```

等域名解析和备案完成后，再改成：

```env
APP_HOST=你的域名
APP_URL=https://你的域名
ACME_EMAIL=你的邮箱
```

## 6. 启动服务

```bash
docker compose -f compose.prod.yml up -d --build
```

查看状态：

```bash
docker compose -f compose.prod.yml ps
docker compose -f compose.prod.yml logs -f web
```

健康检查：

```bash
curl http://127.0.0.1/api/health
```

公网访问：

```bash
curl http://你的服务器公网IP/api/health
```

浏览器打开：

```text
http://你的服务器公网IP
```

## 7. 后续更新

以后代码有更新：

```bash
cd /opt/huoji
git pull
docker compose -f compose.prod.yml up -d --build
```

## 8. 当前限制

当前部署的是 Web 版可用原型，数据仍存在浏览器本地存储。手机号登录也是演示态，短信默认 mock。正式外网试用前，下一步应接入真实数据库、真实短信和持久化账号系统。
