# 货记服务器部署指南

本文档用于把当前 Web 版货记部署到一台已安装 Docker 的云服务器。

## 1. 云服务器控制台

先确认安全组或防火墙已开放：

- `22`：SSH 登录
- `80`：HTTP 访问
- `443`：HTTPS 访问

开发端口如 `5176` 不需要开放到公网。

## 2. 登录服务器

在本机终端执行：

```bash
ssh root@你的服务器公网IP
```

如果云厂商给的是 Ubuntu 普通用户，则使用：

```bash
ssh ubuntu@你的服务器公网IP
```

## 3. 安装基础工具

容器镜像服务器通常已经有 Docker。登录后先检查：

```bash
docker version
docker compose version
```

如果缺少 Git：

```bash
apt update
apt install -y git
```

## 4. 拉取代码

```bash
mkdir -p /opt/huoji
cd /opt/huoji
git clone 你的代码仓库地址 .
```

如果暂时还没有远程 Git 仓库，也可以先用压缩包或 `scp` 上传项目目录。

## 5. 配置生产环境变量

```bash
cp .env.production.example .env.production
nano .env.production
```

先用 IP 测试时：

```env
APP_HOST=:80
APP_URL=http://你的服务器公网IP
DEEPSEEK_API_KEY=你的 DeepSeek Key
SMS_PROVIDER=mock
```

等域名解析和备案完成后，再改成：

```env
APP_HOST=你的域名
APP_URL=https://你的域名
ACME_EMAIL=你的邮箱
```

## 6. 启动服务

```bash
docker compose -f compose.prod.yml up -d --build
```

查看状态：

```bash
docker compose -f compose.prod.yml ps
docker compose -f compose.prod.yml logs -f web
```

健康检查：

```bash
curl http://127.0.0.1/api/health
```

公网访问：

```bash
curl http://你的服务器公网IP/api/health
```

浏览器打开：

```text
http://你的服务器公网IP
```

## 7. 后续更新

以后代码有更新：

```bash
cd /opt/huoji
git pull
docker compose -f compose.prod.yml up -d --build
```

## 8. 当前限制

当前部署的是 Web 版可用原型，数据仍存在浏览器本地存储。手机号登录也是演示态，短信默认 mock。正式外网试用前，下一步应接入真实数据库、真实短信和持久化账号系统。

## 9. 接入阿里云验证码 2.0

阿里云验证码 2.0 是获取短信前的人机验证，用来防止短信接口被刷。它不会发送短信，短信发送仍由 `SMS_PROVIDER` 指定的短信服务商负责。

先在阿里云控制台完成：

- 开通验证码 2.0
- 在概览页获取身份标 `prefix`
- 新建 Web/H5 验证场景，获取场景 ID
- 创建 RAM 子账号 AccessKey，并授予验证码 2.0 服务端验签权限

然后编辑服务器环境变量：

```bash
cd /opt/huoji
nano .env.production
```

修改为：

```env
CAPTCHA_PROVIDER=aliyun
ALIYUN_CAPTCHA_REGION=cn
ALIYUN_CAPTCHA_PREFIX=你的验证码身份标
ALIYUN_CAPTCHA_SCENE_ID=你的验证码场景ID
ALIYUN_CAPTCHA_ACCESS_KEY_ID=你的阿里云AccessKeyId
ALIYUN_CAPTCHA_ACCESS_KEY_SECRET=你的阿里云AccessKeySecret
ALIYUN_CAPTCHA_ENDPOINT=captcha.cn-shanghai.aliyuncs.com
ALIYUN_CAPTCHA_MODE=popup
```

保存后重启：

```bash
sudo docker compose -f compose.prod.yml up -d --build
```

启用后，用户点击“获取验证码”会先完成阿里云验证码 2.0，后端调用 `VerifyIntelligentCaptcha` 验签通过后，才会继续发送短信。

## 10. 接入真实短信验证码

当前服务支持腾讯云短信。先在腾讯云控制台完成：

- 开通短信服务
- 创建短信应用，取得 `SmsSdkAppId`
- 申请并审核通过短信签名
- 申请并审核通过验证码短信模板
- 创建腾讯云访问密钥，建议使用只允许短信 `SendSms` 的子账号密钥

然后编辑服务器环境变量：

```bash
cd /opt/huoji
nano .env.production
```

修改为：

```env
SMS_PROVIDER=tencentcloud
SMS_RESEND_COOLDOWN_SECONDS=60

TENCENTCLOUD_SECRET_ID=你的 SecretId
TENCENTCLOUD_SECRET_KEY=你的 SecretKey
TENCENT_SMS_SDK_APP_ID=你的短信应用 ID
TENCENT_SMS_SIGN_NAME=你的短信签名内容
TENCENT_SMS_TEMPLATE_ID=你的短信模板 ID
TENCENT_SMS_REGION=ap-guangzhou
TENCENT_SMS_ENDPOINT=sms.tencentcloudapi.com
```

短信模板变量顺序要和控制台审核通过的模板一致：

```env
# 模板只有 {1}=验证码
TENCENT_SMS_TEMPLATE_PARAMS=code

# 模板为 {1}=验证码、{2}=有效分钟数
TENCENT_SMS_TEMPLATE_PARAMS=code,ttl
```

保存后重启：

```bash
sudo docker compose -f compose.prod.yml up -d --build
sudo docker compose -f compose.prod.yml logs --tail=80 web
```

浏览器退出登录后重新获取验证码。如果腾讯云返回模板不匹配、签名未审核、余额不足等错误，接口会把错误信息返回给前端和日志，按错误码处理即可。
