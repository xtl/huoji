第一步

电脑上安装助手

在 Windows 电脑登录微信，再登录货记。打开「消息 → 微信采集」，按提示下载安装，已经装过就直接启动。

第二步

选一个常看的群

第一次可以从近 1 天开始。想多看几天，在「补采历史」选近 3 天或 7 天。

第三步

让助手翻，让 AI 整理

助手自动往上翻，去掉重复消息。AI 分出货源和求购，提取型号、数量等信息。

第四步

留下值得跟进的消息

回「微信采集」把有用的消息加入「待入库」，核对后保存。之后可以按型号查找，也能看有哪些供需对得上。

打开微信采集

有人催货，也有人手上有货等买家

有货，先看看谁在收

刚到货，不用等别人来问。用型号找求购，看看数量和交付地对不对得上。有买家托你找货，就反过来查供应。

群里找不到，发给更多同行看

上内圈看看有没有刚发的货源或求购。个人会员可以把自己要找的型号、数量和城市发出来。

有兴趣，直接和发帖的人聊

个人会员看到合适的，点「询价」或「我能供货」，直接问价格、库存和交付。对方回复后，在「消息」里接着聊。

企业版

同事各自记，公司统一管

公司通过认证后，就能邀请同事加入。每个人管理自己收集的货源和求购，老板和管理员可以查看团队资料、管理员工发布的帖子，也能看公司用了多少 AI 额度。

进入企业空间

开始之前

在微信里打开后，可以直接采集群消息吗？

手机可以打开货记浏览内圈和处理会话。自动采集需要在 Windows 电脑运行货记采集助手，并选择要采集的群。

群消息采集后会发到内圈吗？

采集用于整理所选工作空间的资料。内圈发布是单独的操作，由你决定发布哪条供需。
